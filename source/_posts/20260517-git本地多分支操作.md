# git本地多分支操作

## 查看所有分支

```shell
git branch
```


## 创建新分支

```shell
git branch 分支名
```

## 回滚当前分支

```shell
git reset --hard HEAD~1
```

## 切换分支

```shell
git checkout 分支名
```

## 合并分支到当前分支
```shell
git merge 分支名
```

## 删除分支
```shell
git branch -d 分支名
```
