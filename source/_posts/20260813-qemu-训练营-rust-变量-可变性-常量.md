# qemu 训练营:rust 变量,可变性,常量

> 这个章节（rustlings 的 variables 章节）是 Rust 入门的基础，通过 6 个练习讲解了关于变量绑定的核心知识点。

## 一、变量声明（let 关键字）

- **variables1**：Rust 中创建变量绑定必须使用 `let` 关键字，这是声明变量的唯一方式（除了 `const` 和 `static`）。
- **variables2**：变量声明时可以显式标注类型（如 `let x: i32 = 10;`），也强调 Rust 要求编译器必须能推断出变量类型。

## 二、类型注解与推断

- **variables2 的关键点**：Rust 是静态强类型语言，但支持类型推断（type inference）。当编译器无法从上下文推断出类型时，必须手动标注类型（type annotation）。

## 三、声明与初始化

- **variables3**：变量可以先声明后初始化（`let x: i32;` 再 `x = 3;`），但在使用之前必须完成赋值，否则编译器会报错（"use of possibly-uninitialized variable"）。这体现了 Rust 编译期就能捕获未初始化使用的问题。

## 四、可变性（Mutability）

- **variables4**：Rust 中变量默认不可变（immutable）。如果需要重新赋值，必须用 `mut` 关键字声明为可变（`let mut x = 3;`）。这是 Rust 安全性和可读性设计的核心特性之一。

## 五、变量遮蔽（Shadowing）

- **variables5**：用 `let` 重新声明同名变量，会遮蔽（shadow）之前的变量。与 `mut` 的区别在于：
  - 遮蔽可以改变变量类型（如从字符串 "T-H-R-E-E" 变为数字 3）；
  - 遮蔽创建的是一个新绑定，原变量仍存在但被隐藏；
  - 遮蔽后的变量默认仍是不可变的（除非加 `mut`）。

## 六、常量（const）

- **variables6**：常量的声明方式与变量不同：
  - 使用 `const` 关键字而不是 `let`；
  - 必须显式标注类型（如 `const NUMBER: i32 = 3;`）；
  - 常量永远不可变（不需要也不能用 `mut`）；
  - 常量在编译期求值，可以用于数组长度等场景。

## 小结

这个章节的核心脉络是：声明变量（`let`）→ 类型推断与注解 → 先声明后初始化 → 默认不可变与 `mut` → 遮蔽（类型转换的惯用方式）→ 常量（`const`）。整体对应《Rust 程序设计语言》第 3 章的 "Variables and Mutability" 一节，为后续学习所有权、引用等更深入的概念打下基础。
