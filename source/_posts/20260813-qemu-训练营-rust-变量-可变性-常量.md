## rust 的变量的特点

1. rust 变量的类型可以自动推导
2. rust 变量默认都是不可变的
3. rust 变量值的变化可以通过 添加mut属性 或者直接覆盖两种方法

## 一、变量声明（let 关键字）

rust 在生命变量时可以进行自动类型推导，也可以手动声明类型。下面两种写法都可以通过编译。  
应用可以不初始化,但是使用变量之前变量必须要进行赋值

```rust
fn main() {
    let x = 5;
    println!("x has the value {}", x);
}
```

```rust
fn main() {
    let x: i32;
    x = 5;
    println!("Number {}", x);
}
```

## 二、常用数据类型

| 类别 | 类型 | 说明 |
| --- | --- | --- |
| 整数 | `i8`~`i128`、`u8`~`u128` | 有符号/无符号整数 |
| 平台整数 | `isize`、`usize` | 与机器位数相关（64位系统为 64 位） |
| 浮点数 | `f32`、`f64` | 单精度/双精度浮点，默认 `f64` |
| 布尔 | `bool` | `true` / `false` |
| 字符 | `char` | 单个 Unicode 字符（4 字节） |

# 三、数据的修改

rust 变量默认是无法被修改，如果需要变量进行修改需要加上mut 关键字声明可变变量。或者使用let 关键字对变量进行覆盖。

1. 可变变量声明
```rust
fn main() {
    let mut x = 3;
    println!("Number {}", x);
    x = 5; // don't change this line
    println!("Number {}", x);
}
```

## 三、声明与初始化

- **variables3**：变量可以先声明后初始化（`let x: i32;` 再 `x = 3;`），但在使用之前必须完成赋值，否则编译器会报错（"use of possibly-uninitialized variable"）。这体现了 Rust 编译期就能捕获未初始化使用的问题。

## 四、可变性（Mutability）

- **variables4**：Rust 中变量默认不可变（immutable）。如果需要重新赋值，必须用 `mut` 关键字声明为可变（`let mut x = 3;`）。这是 Rust 安全性和可读性设计的核心特性之一。

## 五、变量遮蔽（Shadowing）

- **variables5**：用 `let` 重新声明同名变量，会遮蔽（shadow）之前的变量。与 `mut` 的区别在于：
  - 遮蔽可以改变变量类型（如从字符串 "T-H-R-E-E" 变为数字 3）；
  - 遮蔽创建的是一个新绑定，原变量仍存在但被隐藏；
  - 遮蔽后的变量默认仍是不可变的（除非加 `mut`）。

## 六、常量（const）

- **variables6**：常量的声明方式与变量不同：
  - 使用 `const` 关键字而不是 `let`；
  - 必须显式标注类型（如 `const NUMBER: i32 = 3;`）；
  - 常量永远不可变（不需要也不能用 `mut`）；
  - 常量在编译期求值，可以用于数组长度等场景。
