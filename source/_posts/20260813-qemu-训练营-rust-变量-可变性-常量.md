# qemu 训练营:rust 变量,可变性,常量

> 泽文大大万岁，感谢泽文大大组织的qemu训练营。[@泽文 zevorn github](https://github.com/zevorn)。

## rust 的变量的特点

1. rust 变量的类型可以自动推导
2. rust 变量默认都是不可变的
3. rust 变量值的变化可以通过 添加mut属性 或者直接覆盖两种方法

## 一、变量声明（let 关键字）

rust 在生命变量时可以进行自动类型推导，也可以手动声明类型。下面两种写法都可以通过编译。  
应用可以不初始化,但是使用变量之前变量必须要进行赋值

```rust
fn main() {
    let x = 5;
    println!("x has the value {}", x);
}
```

```rust
fn main() {
    let x: i32;
    x = 5;
    println!("Number {}", x);
}
```

## 二、常用数据类型

| 类别 | 类型 | 说明 |
| --- | --- | --- |
| 整数 | `i8`~`i128`、`u8`~`u128` | 有符号/无符号整数 |
| 平台整数 | `isize`、`usize` | 与机器位数相关（64位系统为 64 位） |
| 浮点数 | `f32`、`f64` | 单精度/双精度浮点，默认 `f64` |
| 布尔 | `bool` | `true` / `false` |
| 字符 | `char` | 单个 Unicode 字符（4 字节） |

# 三、数据的修改

rust 变量默认是无法被修改，如果需要变量进行修改需要加上mut 关键字声明可变变量。或者使用let 关键字对变量进行覆盖。

1. 可变变量声明
```rust
fn main() {
    let mut x = 3;
    println!("Number {}", x);
    x = 5; // don't change this line
    println!("Number {}", x);
}
```
2. 变量覆盖（变量遮蔽）
```rust
fn main() {
    let number = "T-H-R-E-E"; // don't change this line
    println!("Spell a Number : {}", number);
    let number = 3; // don't rename this variable
    println!("Number plus two is : {}", number + 2);
}
```
