# AI 规范驱动开发 SDD

## OpenSpec 

### 常用指令

| 命令 | 作用 |
| --- | --- |
| `/opsx:explore` | 不确定怎么做？先和 AI 探索方案、权衡利弊 |
| `/opsx:propose <功能名>` | AI 自动生成 proposal / specs / design / tasks 四件套 |
| `/opsx:apply` | AI 按任务清单逐项实现 |
| `/opsx:archive` | 完成后归档，delta specs 合并进主规格 |
