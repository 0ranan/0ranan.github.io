# kubectl 使用指南

`kubectl` 是 Kubernetes 集群管理器（Kubernetes cluster manager）的命令行工具，通过它可以在终端里对集群资源进行增删改查和调试。更多信息见 `https://kubernetes.io/docs/reference/kubectl/`。

## 用法

```bash
kubectl [flags] [options]

kubectl <command> --help   # 查看某个命令的详细帮助
kubectl options            # 查看全局命令行选项
```

`kubectl` 的命令按类别划分，下面按类别列出。

## 基本命令（初学者）

| 命令 | 说明 |
|------|------|
| `create` | 从文件或标准输入创建资源。 |
| `expose` | 将一个 replication controller、service、deployment 或 pod 公开为新的 Kubernetes 服务。 |
| `run` | 在集群上运行特定镜像。 |
| `set` | 为对象设置指定特性。 |

## 基本命令（进阶）

| 命令 | 说明 |
|------|------|
| `explain` | 获取某个资源的文档。 |
| `get` | 显示一个或多个资源。 |
| `edit` | 编辑服务器上的资源。 |
| `delete` | 通过文件名、标准输入、资源名或标签选择器删除资源。 |

## 部署命令

| 命令 | 说明 |
|------|------|
| `rollout` | 管理资源的滚动发布（rollout）。 |
| `scale` | 为 deployment、replica set 或 replication controller 设置新的规模。 |
| `autoscale` | 自动扩缩容 deployment、replica set、stateful set 或 replication controller。 |

## 集群管理命令

| 命令 | 说明 |
|------|------|
| `certificate` | 修改证书资源。 |
| `cluster-info` | 显示集群信息。 |
| `top` | 显示资源（CPU/内存）使用情况。 |
| `cordon` | 标记节点为不可调度。 |
| `uncordon` | 标记节点为可调度。 |
| `drain` | 清空节点以准备维护。 |
| `taint` | 更新一个或者多个节点上的污点。 |

## 故障排查与调试命令

| 命令 | 说明 |
|------|------|
| `describe` | 显示特定资源或资源组的详细信息。 |
| `logs` | 打印 Pod 中容器的日志。 |
| `attach` | 挂接到一个运行中的容器。 |
| `exec` | 在某个容器中执行一个命令。 |
| `port-forward` | 将一个或多个本地端口转发到某个 Pod。 |
| `proxy` | 运行一个指向 Kubernetes API 服务器的代理。 |
| `cp` | 在容器与本地之间复制文件或目录。 |
| `auth` | 检查授权。 |
| `debug` | 为故障排查工作负载和节点创建调试会话。 |
| `events` | 列出事件。 |

## 高级命令

| 命令 | 说明 |
|------|------|
| `diff` | 将当前实时版本与将要应用的版本进行对比。 |
| `apply` | 通过文件名或标准输入对资源应用配置。 |
| `patch` | 更新资源的字段。 |
| `replace` | 通过文件名或标准输入替换资源。 |
| `wait` | 实验性：等待一个或多个资源满足特定条件。 |
| `kustomize` | 从目录或 URL 构建 kustomization 目标。 |

## 设置命令

| 命令 | 说明 |
|------|------|
| `label` | 更新某资源上的标签。 |
| `annotate` | 更新一个资源的注解。 |
| `completion` | 输出指定 shell（bash、zsh、fish 或 powershell）的 shell 补全代码。 |

## 其他命令

| 命令 | 说明 |
|------|------|
| `api-resources` | 在服务器上打印受支持的 API 资源。 |
| `api-versions` | 以 "group/version" 的形式打印服务器支持的 API 版本。 |
| `config` | 修改 kubeconfig 文件。 |
| `plugin` | 提供与插件交互的工具。 |
| `version` | 输出客户端和服务端的版本信息。 |

## 获取帮助

在终端运行 `kubectl --help` 或 `kubectl <command> --help` 可以查看对应的帮助信息，运行 `kubectl options` 可以查看全局命令行选项。
