# kubectl 使用指南

`kubectl` 是 Kubernetes 集群管理器（Kubernetes cluster manager）的命令行工具，通过它可以在终端里对集群资源进行增删改查和调试。更多信息见 `https://kubernetes.io/docs/reference/kubectl/`。

## 安装

注意：kubectl 客户端与集群版本的差异必须保持在一个小版本号内，例如 v1.37 的客户端可与 v1.36、v1.37、v1.38 的控制面通信。官方安装教程见 `https://kubernetes.io/zh-cn/docs/tasks/tools/install-kubectl-linux/`。
## 用法

```bash
kubectl [flags] [options]

kubectl <command> --help   # 查看某个命令的详细帮助
kubectl options            # 查看全局命令行选项
```

`kubectl` 的命令按类别划分，下面按类别列出。

## kubectl config

`kubectl config` 通过子命令修改 kubeconfig 文件，例如 `kubectl config set current-context my-context`。

### 加载顺序

kubeconfig 文件的加载遵循以下规则：

1. 如果设置了 `--kubeconfig` 参数，则只加载该文件。该参数只能设置一次，且不进行合并。
2. 如果设置了 `$KUBECONFIG` 环境变量，则将其作为路径列表使用（遵循系统正常的分隔符规则），这些路径会合并。修改某个值时，在定义该配置段的文件中修改；新增某个值时，在链上第一个存在的文件中创建。如果链上没有文件存在，则在列表最后一个文件创建。
3. 否则使用 `${HOME}/.kube/config`，且不进行合并。

### 可用子命令

| 命令 | 说明 |
|------|------|
| `current-context` | 显示当前上下文。 |
| `delete-cluster` | 从 kubeconfig 中删除指定的集群。 |
| `delete-context` | 从 kubeconfig 中删除指定的上下文。 |
| `delete-user` | 从 kubeconfig 中删除指定的用户。 |
| `get-clusters` | 显示在 kubeconfig 中定义的集群。 |
| `get-contexts` | 描述一个或多个上下文。 |
| `get-users` | 显示在 kubeconfig 中定义的用户。 |
| `rename-context` | 重命名 kubeconfig 文件中的一个上下文。 |
| `set` | 在 kubeconfig 文件中设置单个值。 |
| `set-cluster` | 在 kubeconfig 中设置一个集群条目。 |
| `set-context` | 在 kubeconfig 中设置一个上下文条目。 |
| `set-credentials` | 在 kubeconfig 中设置一个用户条目。 |
| `unset` | 取消设置 kubeconfig 文件中的单个值。 |
| `use-context` | 在 kubeconfig 文件中设置当前上下文。 |
| `view` | 显示合并的 kubeconfig 配置或指定的一个 kubeconfig 文件。 |

### 用法

```bash
kubectl config SUBCOMMAND [options]

kubectl config <command> --help   # 查看某个子命令的详细帮助
```

## 获取帮助

在终端运行 `kubectl --help` 或 `kubectl <command> --help` 可以查看对应的帮助信息，运行 `kubectl options` 可以查看全局命令行选项。
