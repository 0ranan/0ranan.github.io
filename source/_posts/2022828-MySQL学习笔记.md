# MySQL学习笔记

## 通用
### 跳转到某个数据库
```mysql 
USE anran0
```
### 显示所有的数据库
```mysql
SHOW DATABASES
```
### 显示当前数据库所有的数据表
```mysql
SHOW  TABLES;
```
### 显示所有的键
```mysql
SHOW COLUMNS FROM 数据表名;
```
