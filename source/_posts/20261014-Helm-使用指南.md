# Helm 使用指南

Kubernetes 的包管理器（Kubernetes package manager）

## 安装

Helm 的安装方式分为官方方式（二进制发行包、安装脚本）和社区提供的包管理器方式。官方安装文档见 `https://helm.sh/docs/intro/install/`。

安装完成后运行 `helm help` 验证。

Helm 的常用操作：

- helm search：搜索 chart
- helm pull：将 chart 下载到本地目录以便查看
- helm install：将 chart 上传到 Kubernetes
- helm list：列出 chart 的 release

环境变量：

| 名称 | 说明 |
|------|------|
| $HELM_CACHE_HOME | 设置缓存文件的存储位置。 |
| $HELM_CONFIG_HOME | 设置 Helm 配置文件的存储位置。 |
| $HELM_DATA_HOME | 设置 Helm 数据的存储位置。 |
| $HELM_DEBUG | 指示 Helm 是否运行在 Debug 模式。 |
| $HELM_DRIVER | 设置后端存储驱动。可选值：configmap、secret、memory、sql。 |
| $HELM_DRIVER_SQL_CONNECTION_STRING | 设置 SQL 存储驱动使用的连接字符串。 |
| $HELM_MAX_HISTORY | 设置 Helm release 历史记录的最大保存数量。 |
| $HELM_NAMESPACE | 设置 Helm 操作使用的命名空间。 |
| $HELM_NO_PLUGINS | 禁用插件。设置 HELM_NO_PLUGINS=1 可禁用插件。 |
| $HELM_PLUGINS | 设置插件目录的路径。 |
| $HELM_REGISTRY_CONFIG | 设置 registry 配置文件的路径。 |
| $HELM_REPOSITORY_CACHE | 设置仓库缓存目录的路径。 |
| $HELM_REPOSITORY_CONFIG | 设置仓库配置文件的路径。 |
| $KUBECONFIG | 设置备用的 Kubernetes 配置文件（默认 "~/.kube/config"）。 |
| $HELM_KUBEAPISERVER | 设置用于认证的 Kubernetes API Server 端点。 |
| $HELM_KUBECAFILE | 设置 Kubernetes 证书颁发机构（CA）文件。 |
| $HELM_KUBEASGROUPS | 以逗号分隔的列表设置用于模拟（impersonation）的用户组。 |
| $HELM_KUBEASUSER | 设置操作时模拟（impersonate）的用户名。 |
| $HELM_KUBECONTEXT | 设置 kubeconfig 上下文的名称。 |
| $HELM_KUBETOKEN | 设置用于认证的 Bearer KubeToken。 |
| $HELM_KUBEINSECURE_SKIP_TLS_VERIFY | 指示是否跳过 Kubernetes API Server 的证书校验（不安全）。 |
| $HELM_KUBETLS_SERVER_NAME | 设置用于校验 Kubernetes API Server 证书的服务器名称。 |
| $HELM_BURST_LIMIT | 设置服务器包含大量 CRD 时的默认突发限制（burst limit）（默认 100，-1 表示禁用）。 |
| $HELM_QPS | 在调用量很高、需要更高 burst 值时，设置每秒查询数（Queries Per Second）。 |
| $HELM_COLOR | 设置彩色输出模式。可选值：never、always、auto（默认 never）。 |
| $NO_COLOR | 设置为任意非空值可禁用所有彩色输出（会覆盖 $HELM_COLOR）。 |
| $SOURCE_DATE_EPOCH | 设置 Unix 时间戳，用于生成可复现（reproducible）的 chart 归档包。 |

Helm 按以下顺序确定缓存、配置和数据的存储位置：

- 如果设置了 HELM_*_HOME 环境变量，则使用它
- 否则，在支持 XDG base directory 规范的系统中，使用 XDG 变量
- 如果以上都未设置，则根据操作系统使用默认位置

默认目录取决于操作系统，各系统的默认值如下：

| 操作系统 | 缓存路径 | 配置路径 | 数据路径 |
|------------------|------------|--------------------|-----------|
| Linux | $HOME/.cache/helm | $HOME/.config/helm | $HOME/.local/share/helm |
| macOS | $HOME/Library/Caches/helm | $HOME/Library/Preferences/helm | $HOME/Library/helm |
| Windows | %TEMP%\helm | %APPDATA%\helm | %APPDATA%\helm |

用法：

```bash
helm [command]
```

可用命令：

| 命令 | 说明 |
|------|------|
| completion | 为指定的 shell 生成自动补全脚本。 |
| create | 使用给定的名称创建一个新 chart。 |
| dependency | 管理 chart 的依赖。 |
| env | 显示 Helm 客户端的环境信息。 |
| get | 下载指定 release 的扩展信息。 |
| help | 查看任意命令的帮助。 |
| history | 获取 release 的历史记录。 |
| install | 安装 chart。 |
| lint | 检查 chart 是否存在潜在问题。 |
| list | 列出 release。 |
| package | 将 chart 目录打包成 chart 归档包。 |
| plugin | 安装、列出或卸载 Helm 插件。 |
| pull | 从仓库下载 chart，（可选）在本地目录解包。 |
| push | 将 chart 推送到远端。 |
| registry | 登录或登出 registry。 |
| repo | 添加、列出、删除、更新 chart 仓库，以及生成仓库索引。 |
| rollback | 将 release 回滚到之前的版本。 |
| search | 在 chart 中搜索关键字。 |
| show | 显示 chart 的信息。 |
| status | 显示指定 release 的状态。 |
| template | 在本地渲染模板。 |
| test | 对 release 运行测试。 |
| uninstall | 卸载 release。 |
| upgrade | 升级 release。 |
| verify | 验证指定路径的 chart 是否已签名且有效。 |
| version | 打印 Helm 版本信息。 |

全局参数：

| 参数 | 说明 |
|------|------|
| --burst-limit int | 客户端默认限流阈值（默认 100）。 |
| --color string | 使用彩色输出（never、auto、always）（默认 "auto"）。 |
| --colour string | 使用彩色输出（never、auto、always）（默认 "auto"）。 |
| --content-cache string | 缓存内容（例如 chart）所在目录的路径（默认 "/home/admin/.cache/helm/content"）。 |
| --debug | 开启详细输出。 |
| -h, --help | Helm 的帮助信息。 |
| --kube-apiserver string | Kubernetes API Server 的地址和端口。 |
| --kube-as-group stringArray | 操作时模拟（impersonate）的用户组，可重复指定以传入多个组。 |
| --kube-as-user string | 操作时模拟（impersonate）的用户名。 |
| --kube-ca-file string | 连接 Kubernetes API Server 所用的证书颁发机构（CA）文件。 |
| --kube-context string | 使用的 kubeconfig 上下文名称。 |
| --kube-insecure-skip-tls-verify | 若为 true，则不校验 Kubernetes API Server 证书的有效性，这会使 HTTPS 连接不安全。 |
| --kube-tls-server-name string | 用于校验 Kubernetes API Server 证书的服务器名称。若未提供，则使用访问服务器时用到的主机名。 |
| --kube-token string | 用于认证的 bearer token。 |
| --kubeconfig string | kubeconfig 文件的路径。 |
| -n, --namespace string | 本次请求的命名空间范围。 |
| --qps float32 | 与 Kubernetes API 通信时使用的每秒查询数（QPS），不包括 burst。 |
| --registry-config string | registry 配置文件的路径（默认 "/home/admin/.config/helm/registry/config.json"）。 |
| --repository-cache string | 缓存的仓库索引所在目录的路径（默认 "/home/admin/.cache/helm/repository"）。 |
| --repository-config string | 包含仓库名称和 URL 的文件路径（默认 "/home/admin/.config/helm/repositories.yaml"）。 |

使用 `helm [command] --help` 可查看某个命令的更多信息。
