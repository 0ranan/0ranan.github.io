# Hexo建站

### 安装

##### 	安装Git

##### 	安装Note.js

##### 	安装淘宝镜像源

```cmd
#安装淘宝镜像源
npm install -g cnpm --registry=https://registry.npm.taobao.org
```

##### 	下载hexo

```
cnpm install -g hexo-cli
```

### 部署hexo

#### 初始化hexo目录

```cmd
::创建blog目录
mkdir blog
#移动到blog目录
cd blog
#使用hexo初始化当前目录
hexo init
```

#### 启动hexo

```
hexo server
```

#### 创建gitee仓库

> 国内github总是部署失败，所以部署到gitee
>
> 创建一个仓库
> 仓库名则为自己的gitee名
>
> 我的为an-ran0

#### 安装部署hexo的插件

```cmd
cnpm install --save hexo-deployer-git
```

#### 修改站点配置文件

> 打开_confing.yml
>
> 打开最后看到
>
> ```text
> deploy:
> type: 
> repo:
> ```
> 改成
> ```text
> deploy:
> type: git
> repo: https://github.com/ yourname/yourname.github.io.git
>   branch: master
>   ```
>
>

#### 部署到gitee

```text
//部署
hexo deploy
//缩写
hexo text
```
