# adb的日常使用

## adb检查设备是否在线

```
adb devices
```



## adb安装apk

```
adb install app.apk
```

## adb命令截图

//截图保存在android箱中

```
adb shell screencap -p /sdcard/screen.png
```

//默认把android箱中的screen.png导出到cmd目录运行的位置

```
adb pull /sdcard/screen.png 导出的目标目录（可空）
```

## adb命令导出apk

//查看手机收所有apk文件

```
adb shell pm list package
```

//根据要导出的app包名查看app的安装路径

```
adb shell pm path com.DeviceTest
```

//根据路径将文件导出到pc端

```
格式：adb pull 读出的路径 导出的目标目录
```

```
demo: adb pull /system/priv-app/DeviceTest/DeviceTest.apk C:\Users\Administrator\Desktop\
```
