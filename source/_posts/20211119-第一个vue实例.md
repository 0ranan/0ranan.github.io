# 第一个`vue`实例

```vue

<template>
  <div id="app">
    <img src="./assets/logo.png">
    <div v-text="$data.title">
    </div>
  </div>
</template>

<script>
  export default {
    data: function() {
      return {
        title: "Hello Word!"
      }
    }
  }
</script>
```





## 解析

### 等价语法

1. 

    ```html

    <div v-text="$data.title"></div>
    <!--等价（Vue语法）-->
    <div v-text>
        {{title}}
    </div>

    ```
2. 

   ```javascript
       data: function() {
         return {
           title: "Hello Word!"
         }
       }
    //等价（es6语法）
       data() {
         return {
           title: "Hello Word!"
         }
       }
   ```
