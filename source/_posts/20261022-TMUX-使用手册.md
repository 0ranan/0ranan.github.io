# TMUX 使用手册（官方）

SSH 上去跑一条要十几分钟的命令，网一抖连接断了，进程也跟着没了。tmux 解决的就是这个：命令跑在服务端的会话里，终端断开，会话还在。

下面按 tmux 3.3a 的 TMUX(1) 整理，平时用得到的放前面，手册里的边角放后面。

## 安装和版本

openEuler 用 dnf，Ubuntu 用 apt：

```bash
sudo dnf install -y tmux
# 或者
sudo apt install -y tmux
```

看一眼版本：

```bash
tmux -V
```

```
tmux 3.3a
```

## 结构

tmux 由一个服务端和若干客户端组成，客户端通过 `/tmp/tmux-UID/` 下的 socket 连到服务端。服务端起起来之后，会话和里面的进程都属于它，和当前这个终端没有关系。

- session：一组窗口，有名字，可以被多个客户端同时 attach。
- window：占满整个屏幕，可以再拆成窗格。
- pane：一个独立的伪终端，跑一个进程。

每个对象都有唯一 ID：会话是 `$0`，窗口是 `@0`，窗格是 `%0`。ID 在对象存活期间不会变，名字可以改。窗格的 ID 会通过 `TMUX_PANE` 环境变量传给里面的进程。

窗口可以被多个会话共享（link-window），会话也可以组成 group 共享同一批窗口。

## 启动参数

```bash
tmux [-2CDhlNuVv] [-c shell-command] [-f file] [-L socket-name] [-S socket-path] [-T features] [command [flags]]
```

- `-2`：强制按 256 色处理，等同 `-T 256`
- `-C`：控制模式，给两次（`-CC`）关掉回显
- `-c shell-command`：用默认 shell 执行一条命令
- `-D`：不把服务端放到后台，同时关掉 `exit-empty`
- `-f file`：指定配置文件，默认先读 `/etc/tmux.conf`，再读 `~/.tmux.conf` 或 `$XDG_CONFIG_HOME/tmux/tmux.conf`
- `-L socket-name`：换一个 socket 名，可以同时跑几个互不相干的 tmux 服务端
- `-S socket-path`：直接指定 socket 的完整路径，给了它 `-L` 就作废
- `-N`：即使命令本来会起服务端，也不起
- `-T features`：给客户端设终端特性，逗号分隔
- `-u`：不管 locale 怎么说，都按 UTF-8 输出
- `-V`：版本
- `-v`：详细日志，可叠加

不带命令时默认执行 `new-session`。

## 会话

起一个带名字的会话：

```bash
tmux new -s work
```

在后台起，不占当前终端，直接在里面跑命令：

```bash
tmux new -d -s backup 'rsync -a /data /mnt/disk'
```

会话已经存在就直接 attach，不存在才新建，日常最省事：

```bash
tmux new -A -s work
```

`-A` 还可以配 `-D`（踢掉其他客户端）和 `-X`（只发 SIGHUP）一起用。

列出来：

```bash
tmux ls
tmux list-sessions -F '#{session_name}: #{session_windows} windows, #{?session_attached,attached,detached}'
```

再进去：

```bash
tmux attach -t work
# 简写
tmux a -t work
```

`attach` 加 `-d` 会把其他连着这个会话的客户端踢掉，适合从家里接上公司那台。`-r` 是只读模式，只能看，翻页和脱离还能用。

已经在会话里时，attach 不会嵌套，而是切换到目标会话：

```bash
tmux switch-client -t other
tmux switch-client -l    # 回上一个会话
```

改名、判断存在、关掉：

```bash
tmux rename-session -t work newname
tmux has-session -t work     # 存在返回 0，不存在返回 1
tmux kill-session -t work
tmux kill-session -a -t work # 除了 work 全杀
tmux kill-server             # 连服务端一起收掉
```

`sessions` 还能分组：同一 group 里的会话共享窗口，新建窗口会 link 到组里所有会话。

```bash
tmux new -s work2 -t work
```

## 目标是哪个会话、窗口、窗格

大多数命令用 `-t` 指定目标，形式是 `session:window.pane`。名字支持前缀匹配和 glob，前面加 `=` 就是精确匹配。

```bash
tmux select-window -t work:1
tmux select-pane -t work:1.2
tmux kill-window -t work:1
```

窗口和窗格位置可以写这些特殊 token：

| 写法 | 含义 |
| --- | --- |
| `{start}` / `^` | 编号最小的窗口 |
| `{end}` / `$` | 编号最大的窗口 |
| `{last}` / `!` | 上一个窗口或窗格 |
| `{next}` / `+` | 下一个，可以带偏移，如 `+2` |
| `{previous}` / `-` | 上一个 |
| `{top}` `{bottom}` `{left}` `{right}` | 窗格方位 |
| `{mouse}` / `=` | 最近一次鼠标事件的位置 |
| `{marked}` / `~` | 被标记的窗格 |

```bash
tmux select-window -t:+2
tmux join-pane -s '{marked}' -t:1
```

## 窗口

- `tmux new-window -t work:2 -n logs`：在指定位置新建，`-n` 起名，`-c` 指定工作目录，`-d` 建完不切过去
- `tmux new-window -a` / `-b`：插在当前窗口之后 / 之前
- `tmux new-window -k`：目标位置已有窗口就覆盖
- `tmux select-window -t work:2`、`tmux next-window`、`tmux previous-window`、`tmux last-window`
- `tmux rename-window -t work:2 logs`
- `tmux move-window -s work:2 -t work:5`：挪位置，`-r` 把整个会话的窗口重新按顺序编号
- `tmux link-window -s work:1 -t work2:3`：把窗口链接到另一个会话，`-k` 覆盖目标，`-d` 不切过去
- `tmux unlink-window -t work2:3`：取消链接，只有还链在别的会话时才允许，`-k` 连最后一个会话也断，窗口直接销毁
- `tmux swap-window -s work:1 -t work3:1`：两个窗口对调
- `tmux kill-window -t work:2`，`-a` 只留指定窗口

窗口里的 shell 退出，窗口就关闭。想让它留着看最后的输出，开 `remain-on-exit`：

```bash
tmux set -w remain-on-exit on
tmux respawn-pane -t work:2.0
```

## 窗格

- `tmux split-window -h`：左右分；`-v` 或省略：上下分
- `-l 30` 或 `-l 30%`：新窗格占多少行或列
- `-b`：新窗格放到左边或上边
- `-f`：跨整个窗口切，不局限于当前窗格
- `-d`：分完不切过去
- `tmux select-pane -t work:1.1`，`-L` `-R` `-U` `-D` 选相邻窗格
- `tmux resize-pane -L 5`、`-U 3` 按行/列调，`-x 80`、`-y 24` 调绝对大小，`-Z` 切换全屏
- `tmux swap-pane -s work:1.0 -t work:1.1`，`-U` / `-D` 和相邻的换
- `tmux rotate-window -U` / `-D`：窗格整体转一圈
- `tmux break-pane -t work:1.1`：把窗格拆成独立窗口，`-d` 不切过去
- `tmux join-pane -s work:2 -t work:1`：把某个窗格并进来，`-h` / `-v` 指定方向
- `tmux kill-pane -t work:1.1`，`-a` 只留一个
- `tmux select-pane -m`：标记窗格，`-M` 取消标记；被标记的窗格是 join-pane、swap-pane 的默认源
- `tmux select-pane -T '标题'`：给窗格起标题

多个窗格同时敲一样的命令，比如批量改几台机器：

```bash
tmux setw synchronize-panes on
```

窗口布局有七种预设，`select-layout` 指定，`next-layout` 轮换：

```bash
tmux select-layout -t work:1 even-horizontal
```

`even-horizontal`、`even-vertical`、`main-horizontal`、`main-horizontal-mirrored`、`main-vertical`、`main-vertical-mirrored`、`tiled`。`list-windows` 会打出每个窗口的 layout 字符串，可以原样塞回 `select-layout`。

抓窗格内容：

```bash
tmux capture-pane -p -t work:1.0 -S -3000
```

`-p` 打到 stdout，`-S` / `-E` 指定起止行，负数是历史里的行。开 `-e` 会保留颜色转义。

把窗格输出同时写一份到文件：

```bash
tmux pipe-pane -t work:1.0 -o 'cat >> ~/logs/window.log'
```

`-o` 表示已经有 pipe 就不重复开，再执行一次同样的命令不好使，得先 `tmux pipe-pane -t work:1.0` 关掉。

## copy mode

滚轮默认翻不了 tmux 的历史，要先进 copy mode 才行。`C-b [` 进入，右上角会显示当前位置和总行数。

`mode-keys` 决定用 vi 还是 emacs 键位，默认是 emacs，但 `VISUAL` 或 `EDITOR` 里带 `vi` 时会是 vi：

```bash
tmux set -g mode-keys vi
```

vi 键位常用：

- `j` `k` `h` `l`：上下左右
- `C-f` / `C-b`：翻一页
- `C-d` / `C-u`：翻半页
- `g` / `G`：历史顶部 / 底部
- `/` `?`：向下 / 向上搜，`n` `N` 重复
- `空格`：开始选择；再按一次结束选择
- `v`：矩形选择
- `Enter`：复制并退出
- `q`：退出
- `0` `$` `^`：行首、行尾、第一个非空字符
- `w` `b` `e`：按词移动
- `f` `F` `t` `T`：行内跳到某个字符

emacs 键位里开始选择是 `C-Space`，复制是 `M-w`，退出是 `Escape`，撤销选择 `C-g`。

复制出来的东西进的是 tmux 自己的粘贴缓冲区，`C-b ]` 粘贴。要直接进系统剪贴板，可以在配置里开 `set -g set-clipboard on`（终端得支持 OSC 52），或者用 `copy-pipe` 接到 `xclip` / `wl-copy`：

```bash
tmux bind -T copy-mode-vi Enter send-keys -X copy-pipe-and-cancel 'wl-copy'
```

历史长度默认 2000 行，改 `history-limit`，只对新建的窗口生效：

```bash
tmux set -g history-limit 50000
```

## 粘贴缓冲区

复制的东西、`set-buffer` 塞进去的东西都放在缓冲区栈里。自动命名的是 `buffer0001`、`buffer0002`，超出 `buffer-limit` 就从最旧的开始删；手动命名的不会被自动清理。

```bash
tmux set-buffer '一段文本'
tmux load-buffer -b notes ~/notes.txt
tmux list-buffers
tmux show-buffer -b notes
tmux paste-buffer -b notes -t work:1.0
tmux save-buffer -b notes ~/out.txt
tmux delete-buffer -b notes
```

`paste-buffer -p` 会在粘贴内容两边加括号粘贴控制码，适合往 vim 里贴；`-d` 粘完就删掉这个缓冲区。`C-b #` 列出全部，`C-b =` 交互选一个贴。

## 自定义按键

`bind-key`（简写 `bind`）默认绑在前缀表里，也就是按下前缀之后再按的键：

```bash
tmux bind r source-file ~/.tmux.conf
tmux bind C-l send-keys 'C-l'
```

`-n` 等价于 `-T root`，不加前缀直接生效，容易和程序抢键，慎用。`-T` 可以绑到别的表，比如 `copy-mode-vi`。`-r` 表示这个键可以连按，`repeat-time` 默认 500 毫秒内不用重新按前缀。

`unbind-key` 解绑，`-a` 清空整张表：

```bash
tmux unbind -T prefix x
tmux list-keys -T prefix
```

键名写法：`C-a`（Ctrl）、`M-a`（Alt）、`S-a`（Shift），特殊键有 `Up` `Down` `Left` `Right` `Enter` `Escape` `Space` `Tab` `BSpace` `DC` `IC` `Home` `End` `PageUp` `PageDown` `F1` 到 `F12`。绑 `"` 和 `'` 要加引号：

```bash
bind-key '"' split-window
bind-key "'" new-window
```

`send-keys` 可以往窗格里发键，`send-prefix` 专门把前缀发过去。自定义多级按键用 key table：

```bash
bind-key -T table2 c list-keys
bind-key -T table1 b switch-client -T table2
bind-key -T root   a switch-client -T table1
```

这样按 `a` `b` `c` 就会执行 `list-keys`。

## 配置文件和命令写法

配置文件按顺序读 `/etc/tmux.conf`、`~/.tmux.conf`（或 `$XDG_CONFIG_HOME/tmux/tmux.conf`）。改完在会话里重新加载：

```bash
tmux source-file ~/.tmux.conf
```

也可以 `C-b :` 输入 `source-file ~/.tmux.conf`。

配置文件里每一行就是一条 tmux 命令，不需要写 `tmux` 前缀。分号可以分隔多条命令，但写在 shell 里时要转义：

```bash
tmux neww \; splitw
```

引号包住含空格的参数，花括号包住一组命令，`\` 结尾表示续行，`#` 开头是注释。`%if` / `%elif` / `%else` / `%endif` 可以按条件读配置：

```
%if "#{==:#{host},myhost}"
set -g status-style bg=red
%else
set -g status-style bg=blue
%endif
```

命令都有别名，配置里常写短的：`new`（new-session）、`neww`（new-window）、`splitw`、`selectp`、`selectw`、`renamew`、`killp`、`killw`、`ls`、`lsp`、`lsw`、`set`、`show`、`bind`、`source`、`attach`、`detach`。

## 选项

选项分 server、session、window、pane 四个作用域，窗格选项从窗口选项继承。设置和查看：

```bash
tmux set -g mouse on          # 全局会话选项
tmux set -w remain-on-exit on  # 当前窗口
tmux set -p synchronize-panes on
tmux set -s escape-time 10     # 服务端
tmux show -g
tmux show -wv remain-on-exit   # 只打值
```

`-u` 取消设置，让它继承上层；`-U` 连窗口里所有窗格一起取消；`-a` 往字符串或样式后面追加；`-o` 已经设置过就不覆盖；`-q` 不报错。自定义变量用 `@` 开头：

```bash
tmux set -g @foo abc
tmux show -gv @foo
```

常用的这些：

| 选项 | 作用 | 备注 |
| --- | --- | --- |
| `prefix` | 前缀键 | 默认 `C-b`，可设 `None` 关掉 |
| `prefix2` | 第二前缀 | 默认无 |
| `mouse` | 鼠标支持 | 默认 off |
| `history-limit` | 历史行数 | 默认 2000，只对新窗口生效 |
| `base-index` | 窗口起始编号 | 默认 0 |
| `pane-base-index` | 窗格起始编号 | 默认 0 |
| `renumber-windows` | 关窗口后重排编号 | 默认 off |
| `mode-keys` | copy mode 键位 | `vi` 或 `emacs` |
| `status` | 状态栏 | `off` `on` `2` 到 `5` 行 |
| `status-position` | 状态栏位置 | `top` 或 `bottom` |
| `status-interval` | 状态栏刷新间隔 | 默认 15 秒 |
| `status-left` / `status-right` | 左右内容 | 支持格式和 `strftime` |
| `status-left-length` / `status-right-length` | 左右最大长度 | 默认 10 / 40 |
| `default-shell` | 默认 shell | 要写完整路径 |
| `default-terminal` | 新窗口的 TERM | 必须是 `screen` 或 `tmux` 系 |
| `default-size` | 新窗口默认尺寸 | 默认 80x24 |
| `automatic-rename` | 自动按当前命令改名 | 手动改名后该窗口关闭此功能 |
| `remain-on-exit` | 进程退出后保留窗格 | `on` `off` `failed` |
| `synchronize-panes` | 输入同步到所有窗格 | 窗格选项 |
| `aggressive-resize` | 按最小/最大会话调整窗口 | 全屏程序友好，shell 不友好 |
| `window-size` | 窗口尺寸依据 | `largest` `smallest` `manual` `latest` |
| `escape-time` | 判断转义序列的等待时间 | 毫秒 |
| `focus-events` | 转发焦点事件 | 改完要重新 attach |
| `set-clipboard` | 终端剪贴板 | `on` `external` `off` |
| `allow-passthrough` | 允许应用绕过 tmux | `on` `off` `all` |
| `monitor-activity` | 监控窗口活动 | 状态栏高亮 |
| `visual-activity` | 用消息代替响铃 | `on` `off` `both` |
| `display-time` | 消息显示时长 | 毫秒，0 表示等按键 |
| `word-separators` | copy mode 的词分隔符 | |
| `pane-border-status` | 窗格边框标题 | `off` `top` `bottom` |
| `pane-border-format` | 窗格标题格式 | |
| `pane-scrollbars` | 窗格滚动条 | `off` `modal` `on` |

配置示例，接着前面那份：

```bash
set -g mouse on
set -g history-limit 50000
set -g base-index 1
setw -g pane-base-index 1
set -g renumber-windows on

unbind C-b
set -g prefix C-a
bind C-a send-prefix

bind h select-pane -L

```

`base-index` 只对新建会话生效，已经在跑的会话里窗口还是从 0 开始，想看到 1 得 `tmux kill-session` 再起一个。

## 状态栏

默认一行，从左到右是 `[会话名]`、窗口列表、当前窗格标题（双引号里）、时间日期。

窗口名后面的标志：

- `*` 当前窗口
- `-` 上一个窗口
- `#` 有活动
- `!` 有响铃
- `~` 静默太久
- `M` 里面有被标记的窗格
- `Z` 当前窗格处于全屏

多行状态栏从 tmux 2.9 起用 `status-format` 配，`status 2` 到 `5` 指定行数。默认那行等于把左右内容和窗口列表拼起来，所以只改左右和窗口格式就够日常用了：

```bash
set -g window-status-format ' #I:#W '
set -g window-status-current-format ' #[fg=black,bg=green] #I:#W '
set -g status-justify centre
set -g status-position top
```

`#I` 是窗口编号，`#W` 是窗口名，`#S` 是会话名，`#P` 是窗格编号，`#D` 是窗格 ID，`#F` 是窗口标志，`#H` / `#h` 是主机名。

## 格式字符串

凡是接受 `-F` 的地方都能用 `#{...}`。格式变量可以是内置变量、选项名，也可以是环境变量名：

```bash
tmux display -p '#{session_name}:#{window_index}.#{pane_index} #{pane_current_command}'
tmux list-windows -F '#{window_index} #{window_name} #{?window_active,active,}'
tmux ls -F '#{session_name} #{session_windows} #{?session_attached,attached,detached}'
```

常用写法：

- `#{?变量,真,假}`：条件
- `#{==:a,b}`、`#{!=:a,b}`、`#{<:a,b}`：比较，真返回 1
- `#{||:...}`、`#{&&:...}`、`#{!:...}`
- `#{m:模式,字符串}`：glob 匹配，`m/r` 是正则，`m/ri` 忽略大小写
- `#{e|*|f|4:5.5,3}`：算术，`+ - * / %`，`e` 开头
- `#{s/foo/bar/:...}`：字符串替换
- `#{b:path}` / `#{d:path}`：basename / dirname
- `#{t:window_activity}`：时间戳转时间字符串
- `#{=10:pane_title}`：截断，`#{p10:pane_title}` 补到宽度 10
- `#(命令)`：插入命令输出的最后一行，比如 `#(uptime)`
- `#[fg=red,bold]`：在状态栏字符串里嵌样式

`status-left` / `status-right` 还会过一遍 `strftime`，所以 `%H:%M` 这种时间格式直接写。`display-message -a` 可以列出当前能用的格式变量和值。

## 鼠标

```bash
set -g mouse on
```

打开以后默认就能用鼠标选窗格、拖边框调大小、滚轮翻历史、点状态栏切窗口。滚轮在副本模式里翻的是 tmux 历史，不是给应用发滚动事件，vim 里要滚还是得用键盘或者 `M-` 组合。

鼠标事件名由事件加位置组成，比如 `MouseDown1Pane`、`WheelUpPane`、`MouseDrag1Border`、`DoubleClick1Pane`。位置有 `Pane`、`Border`、`Status`、`StatusLeft`、`StatusRight`、`StatusDefault`、`ScrollbarSlider`、`ScrollbarUp`、`ScrollbarDown`。事件有 `WheelUp/Down`、`MouseDown1` 到 `MouseDown3`、`MouseUp`、`MouseDrag`、`MouseDragEnd`、`SecondClick`、`DoubleClick`、`TripleClick`。

在绑定里用 `{mouse}` 指代鼠标所在的位置：

```bash
bind -n WheelUpPane if-shell -F '#{mouse_any_flag}' 'send-keys -M' 'copy-mode -e'
```

`send-keys -M` 可以把鼠标事件原样转给窗格里的程序。

## hooks

命令执行前后、会话和窗格状态变化都能挂命令。`set-hook -g` 设全局，`-w` 窗口，`-p` 窗格，`-u` 取消：

```bash
set-hook -g after-split-window 'select-layout even-vertical'
set-hook -g command-error 'run-shell "echo tmux command failed >>/tmp/tmux.log"'
set-hook -g client-attached 'display-message "attached"'
set-hook -g pane-exited 'display-message "pane gone: #{pane_id}"'
```

命令自己的 after hook 名字是 `after-` 加命令名。`pane-exited`、`pane-died`、`session-created`、`session-closed`、`window-linked`、`window-renamed`、`client-detached` 这些都能用，`show-hooks -g` 看已经挂了什么。

## 环境变量和嵌套

服务端启动时把环境复制成全局环境，每个会话还有自己的环境，新建窗口时合并，会话环境优先。`update-environment` 里的变量会在新建或重新 attach 会话时从客户端更新，默认包括 `DISPLAY`、`SSH_AUTH_SOCK` 之类。

```bash
tmux set-environment -g FOO bar
tmux show-environment -g
tmux set-environment -u FOO
```

tmux 自己会设置 `TMUX` 和 `TMUX_PANE`，新窗口的 `TERM` 是 `screen`（或 `default-terminal` 指定的值）。在 shell 启动脚本里别把 `TERM` 改回去，否则颜色和按键会出问题。

在 tmux 里再启动 tmux，会看到：

```
sessions should be nested with care, unset $TMUX to force
```

真要套娃就 `unset TMUX`。更常见的是外面一层 tmux、里面 attach 远端 tmux，这时内层的 `C-b` 会被外层吃掉，要按两次：

```
C-b C-b
```

如果前缀改成了 `C-a`，就是 `C-a C-a`。另一种办法是用 `-L` 起独立服务端，或者给内层换 prefix。

## 退出消息和排错

客户端脱离时会打一行：

- `[detached (from session work)]`：正常脱离
- `lost tty`：终端或 pty 被销毁
- `terminated`：客户端收到 SIGTERM
- `exited`：没有会话，服务端自己退了
- `server exited unexpectedly`：服务端崩了

常见几句报错：

`no server running on /tmp/tmux-1000/default`：当前没有会话，或者服务端已经退出。`exit-empty` 默认 on，最后一个会话关掉服务端就没了。

`can't find session: work`：名字不对。用 `tmux ls` 看实际名字，名字有前缀匹配，必要时加 `=`。

`duplicate session: work`：同名会话已经存在，用 `tmux new -A -s work` 或者换个名字。

`no space for new pane`：窗口已经太小，分不下了，先把别的窗格关掉或者放大窗口。

`tmux ls` 显示 `(attached)` 但自己进不去：先 `tmux attach -d -t work` 把别的客户端踢掉。

服务端卡住时可以看消息记录：`C-b ~`，或者 `tmux show-messages`。彻底重来就 `tmux kill-server`，注意这会带走所有会话里的进程。

test: 1 windows (created Thu Oct 22 01:56:26 2026)
