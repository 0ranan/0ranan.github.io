# ssh 使用笔记

## 免密登录远程服务器

这是标准配置流程，只需两步：

### 1. 生成本地密钥对

在本地终端执行，一路回车即可（不建议设密码）：

```bash
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
```

执行后，会在 `~/.ssh/` 目录下生成 `id_rsa`（私钥）和 `id_rsa.pub`（公钥）。

### 2. 把公钥上传到服务器

使用内置命令一键复制并授权（替换 user 和 ip）：

```bash
ssh-copy-id user@你的服务器IP
```

按提示输入一次服务器密码，之后再次 SSH 登录就不再需要密码了。

## SSH 端口转发

SSH 端口转发（SSH Tunneling）是一种强大的网络技巧，它利用加密的 SSH 连接作为“隧道”，将网络流量从一个端口安全地导向另一个端口。它主要有三种模式：**本地转发 (-L)**、**远程转发 (-R)** 和**动态转发 (-D)**。

### 🧭 三种SSH端口转发模式详解

| 模式 | SSH参数 | 数据流向 | 核心用途 | 典型场景 |
| :--- | :--- | :--- | :--- | :--- |
| **本地转发** | `-L` | 本地 → 远程 | 访问远程内网中无法直接访问的服务 | 安全访问远程数据库、内网Web管理后台 |
| **远程转发** | `-R` | 远程 → 本地 | 将本地服务安全地暴露给外部网络 | 临时展示本地开发中的网站，或让同事访问你本地的服务 |
| **动态转发** | `-D` | 动态 SOCKS 代理 | 创建一个SOCKS代理，实现更灵活的代理上网 | 突破网络限制，安全浏览网页 |

### 本地转发 (-L)

将本地端口映射到远程服务器的端口，通过本地访问远程内网服务。

```bash
# 格式：ssh -L [本地地址:]本地端口:目标地址:目标端口 用户@远程服务器
# 场景：本地访问远程服务器内网中运行在 3306 端口的 MySQL 数据库
ssh -L 3307:localhost:3306 anran@121.226.87.7

# 连接后，本地访问 localhost:3307 就等同于访问远程服务器的 localhost:3306
# 可以用 mysql 客户端测试
mysql -h 127.0.0.1 -P 3307 -u root -p

# 也可以转发到远程内网的其他机器（远程服务器作为跳板）
# 场景：通过远程服务器访问其内网中 192.168.1.100 的 Web 服务
ssh -L 8080:192.168.1.100:80 anran@121.226.87.7
# 本地访问 http://localhost:8080 即可访问远程内网的 Web 服务

# 后台运行（不打开 shell，只做端口转发）
ssh -fNL 9877:localhost:9876 anran@121.226.87.7 -p 221
# -f 后台运行  -N 不执行远程命令  -L 本地转发
```

### 远程转发 (-R)

将远程服务器的端口映射到本地端口，让外部通过远程服务器访问本地服务。

```bash
# 格式：ssh -R [远程地址:]远程端口:目标地址:目标端口 用户@远程服务器
# 场景：将本地 3000 端口的开发网站暴露给远程服务器
ssh -R 8080:localhost:3000 anran@121.226.87.7

# 连接后，在远程服务器上访问 localhost:8080 就等于访问本地的 localhost:3000
# 远程服务器上测试
curl localhost:8080

# 进阶：允许外部机器访问远程服务器转发的端口（需要远程服务器配置）
# 在远程服务器的 /etc/ssh/sshd_config 中添加：
#   GatewayPorts yes
# 然后重启 sshd，外部即可通过 远程服务器IP:8080 访问你的本地服务
ssh -R 0.0.0.0:8080:localhost:3000 anran@121.226.87.7
```

### 动态转发 (-D)

创建一个本地 SOCKS 代理服务器，所有流量通过远程服务器转发。

```bash
# 格式：ssh -D [本地地址:]本地端口 用户@远程服务器
# 场景：创建本地 SOCKS5 代理，通过远程服务器上网
ssh -D 1080 anran@121.226.87.7

# 后台运行
ssh -fND 1080 anran@121.226.87.7

# 配置浏览器使用代理：
#   代理地址：127.0.0.1
#   代理端口：1080
#   代理类型：SOCKS5

# 也可以用 curl 测试代理是否生效
curl -x socks5://127.0.0.1:1080 http://ifconfig.me
# 返回的 IP 将是远程服务器的 IP 地址
```
