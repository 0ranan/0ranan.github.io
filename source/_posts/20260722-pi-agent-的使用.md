# pi agent 的使用

## 内置指令

Pi 提供了一系列斜杠指令（`/` 指令），用于在会话过程中执行各种操作。

| 指令 | 功能说明 |
|------|----------|
| `/settings` | 打开设置菜单，可配置各种选项 |
| `/model` | 选择模型，可以指定 provider/model 格式（如 `/model anthropic/claude-sonnet-4-20250514`） |
| `/scoped-models` | 管理可用模型列表，控制哪些模型参与 `Ctrl+P` 快捷键切换 |
| `/export` | 导出会话记录，默认导出 HTML，也可指定路径导出 `.html` 或 `.jsonl` 格式 |
| `/import` | 从 JSONL 文件导入并恢复之前的会话 |
| `/share` | 将会话以加密 GitHub Gist 形式分享 |
| `/copy` | 复制上一条助手的消息到剪贴板 |
| `/name` | 给当前会话设置显示名称 |
| `/session` | 显示当前会话信息和统计（如消息数、token 用量等） |
| `/changelog` | 查看变更日志 |
| `/hotkeys` | 显示所有键盘快捷键列表 |
| `/fork` | 从之前的某条用户消息分叉，创建新的会话分支 |
| `/clone` | 在当前会话当前位置复制出一个新会话 |
| `/tree` | 在会话树中导航，切换不同分支 |
| `/trust` | 保存对当前项目的信任状态，供后续会话使用 |
| `/login` | 配置 provider 认证，需指定 provider 名称（如 `/login anthropic`） |
| `/logout` | 移除已有的 provider 认证信息 |
| `/new` | 启动一个新的空白会话 |
| `/compact` | 手动压缩会话上下文，减少 token 占用 |
| `/resume` | 恢复并切换到另一个已有的会话 |
| `/reload` | 重新加载键盘绑定、扩展、技能、提示词、主题和上下文文件 |
| `/quit` | 退出 pi 程序 |

## 常用技巧和快捷键

### 编辑器中

| 技巧 | 操作 |
|------|------|
| 引用文件 | 输入 `@` 模糊搜索项目文件 |
| 路径补全 | `Tab` 键自动补全路径 |
| 多行输入 | `Shift+Enter`（Windows Terminal 用 `Ctrl+Enter`） |
| 粘贴图片 | `Ctrl+V` 或直接将图片拖入终端 |
| 外部编辑器 | `Ctrl+G` 调用 VSCode/nano 等编辑器编辑输入内容 |

### Shell 命令

- `!<cmd>` — 执行命令，结果发给 LLM
- `!!<cmd>` — 执行命令，结果**不**发给 LLM

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+L` | 打开模型选择器 |
| `Ctrl+P` / `Shift+Ctrl+P` | 上下切换已选择的模型 |
| `Shift+Tab` | 循环切换思维链级别（off/minimal/low/medium/high/xhigh/max） |
| `Ctrl+T` | 展开/折叠思维链内容 |
| `Ctrl+O` | 展开/折叠工具输出 |
| `Ctrl+X` | 复制上一条助手消息 |
| `Escape` | 取消/中断 |
| `Ctrl+D` | 清空编辑器为空时退出程序 |
| `Alt+Enter` | 在助手工作时排队发送一条跟进消息 |
| `Alt+Up` | 把排队的消息撤回编辑器 |
| `Ctrl+G` | 用外部编辑器编辑输入 |

### 消息队列

助手正在工作时，你直接打字按 `Enter` 会排队成 **steering 消息**（当前工具执行完后插入），按 `Alt+Enter` 会排队成 **follow-up 消息**（等全部完成后再处理）。按 `Escape` 可以取消排队把消息撤回编辑器。

### 会话管理

| 命令 | 说明 |
|------|------|
| `pi -c` | 启动后直接继续上次会话 |
| `pi -r` | 浏览并选择之前的会话 |
| `pi --name "xxx"` | 启动时设置会话名称 |
| `pi --session <path\|id>` | 打开指定会话 |
| `pi --no-session` | 临时模式，不保存会话 |

更多细节可以查看 `/hotkeys` 查看所有快捷键，或参考 `usage.md` 和 `keybindings.md` 文档。
