# cursor 使用笔记

## Cursor 核心能力总览（含 Commands / Skills）

### 1. 约束与行为层

| 能力 | 作用 | 区分要点 |
|------|------|----------|
| **Rules**（`.cursor/rules/*.mdc`） | 持久指令：编码规范、项目约定、按文件 glob 生效 | 偏「一直要遵守」；模型仍可能忽略 |
| **AGENTS.md** | 项目级总说明，可嵌套子目录 | 比 rule 更简单，适合写硬边界 |
| **User Rules / Memories** | 跨项目的个人偏好 | 全局，不进仓库 |
| **Skills** | 教 Agent「怎么做某类事」的可复用工作流（SKILL.md） | 按场景被触发或 @ 调用；偏流程与领域知识 |
| **Commands** | 斜杠命令，用户显式触发一段固定/半固定指令 | 你主动 `/xxx`；比 Skill 更「点名即用」 |
| **Hooks** | Agent 生命周期上跑脚本（拦 shell、改后格式化、审计） | 确定性：模型拦不住，适合安全/合规 |

> 一句话：Rules/AGENTS = 软约束；Skills/Commands = 可复用工作流；Hooks = 硬闸门。

### 2. 扩展与连接层

| 能力 | 作用 |
|------|------|
| **MCP** | 接外部系统（GitHub、DB、Sentry、浏览器、公司内部 API） |
| **Plugins** | 把 skills + rules + MCP + hooks + commands 打成可安装包，团队共享 |
| **Subagents** | 隔离上下文的专用子代理（探索、审查、修 CI 等） |
| **Cursor SDK** | 在脚本/CI/后端里程序化跑 Agent（不只 IDE） |

> 一句话：MCP 给工具，Subagent 分工作，Plugin 打包分发，SDK 走出 IDE。

### 3. 运行形态

| 能力 | 作用 |
|------|------|
| **Modes** | Agent / Plan / Ask / Debug，同一对话不同工作方式 |
| **Cloud Agents** | 云端 VM 里异步干活：构建、测、浏览器、开 PR |
| **Automations** | 按触发器跑（PR、定时、Slack 等），不必你手敲 prompt |
| **Background / Loop** | 本地会话里后台循环盯任务 |

> 一句话：本地对话是「你在场」；Cloud/Automation 是「你不在场也能跑」。

### 4. 交互与产出

| 能力 | 作用 |
|------|------|
| **@ 上下文** | 精确挂文件、文件夹、文档、Diff、网页等 |
| **Tab / Inline Edit** | 行内补全与局部改写 |
| **Canvas** | 旁开可视化产物（分析、图表、审计结果） |
| **Browser** | Agent 可操作页面做验收/调试 |
| **Bugbot / Security Review** | 专门的代码/安全审查子流程 |

### 5. 怎么选（实用心智模型）

| 想做什么 | 用什么 |
|----------|--------|
| 「始终按规范写」 | Rules / AGENTS.md |
| 「教 Agent 一类工作流」 | Skills |
| 「我点一下就跑」 | Commands |
| 「模型不能绕过」 | Hooks |
| 「连外部系统」 | MCP |
| 「拆复杂任务」 | Subagents |
| 「团队统一配置」 | Plugins |
| 「无人值守」 | Automations / Cloud Agents |
| 「程序里调用 Agent」 | SDK |

### 6. Commands vs Skills（对比总结）

| 维度 | Commands | Skills |
|------|----------|--------|
| **触发方式** | 你输入 `/命令名` | Agent 按描述自动选用，也可 @ |
| **形态** | 一段可执行指令/模板 | 完整 SKILL.md 工作流 + 可选脚本 |
| **典型用途** | 「立刻做这件事」 | 「遇到这类问题就按这套做」 |
| **与 Rules 关系** | 不替代规范；命令跑完仍受 Rules 约束 | 同上；Skill 教流程，Rule 管底线 |

> 个人日常优先级：Rules → MCP → Skills / Commands → Hooks → Subagents；团队化和无人值守再上 Plugins / Automations / Cloud Agents。

## Cursor 自带命令（Commands）

Cursor 提供了一些内置的命令，用于提升开发效率和代码质量。

| 命令 | 功能 | 说明 |
|------|------|------|
| **code-review** | 代码审查 | 检查代码的质量、风格、潜在问题（如逻辑错误、安全漏洞等），帮助提升代码的健壮性和可维护性 |
| **read-branch** | 读取分支信息 | 获取分支的代码内容、提交历史、分支状态等，方便了解分支的具体情况 |
| **explain** | 解释说明 | 解释代码逻辑、技术概念或复杂问题，帮助理解代码的意图或相关技术原理 |
| **in-cloud** | 云端操作 | 在云平台上执行操作（如部署、测试、资源管理等），利用云服务的功能 |
| **multi-model-review** | 多模型审查 | 针对多个 AI 模型（或不同技术模型）进行评估、对比或问题检测，适用于复杂的多模型场景 |
| **simplify** | 简化处理 | 简化代码、文本或流程，让内容更简洁易懂，提升可读性或执行效率 |
| **summarize** | 总结提炼 | 总结信息（如代码逻辑、文档内容、讨论要点等），快速提炼核心内容，方便快速理解关键信息 |

## Cursor 自带技能（Skills）

Cursor 内置了 20 个技能模块，按用途分为四类。

### 创建与配置类

| 命令 | 功能 | 说明 |
|------|------|------|
| **automate** | 定时/触发式 Agent | 创建 Cursor Automation，明确要做「Cursor 自动化」时才用，不是泛指 CI/脚本 |
| **create-hook** | 事件钩子 | 在 Agent 事件前后跑脚本或 prompt 检查（审计、拦截、改输入、注入上下文） |
| **create-rule** | 持久规则 | 创建 `.cursor/rules/` 规则，约束编码规范、项目约定、按文件匹配的指引 |
| **create-skill** | 编写技能 | 编写新的 Agent Skill（SKILL.md），教 Agent 做特定工作流 |
| **create-subagent** | 自定义子代理 | 创建 `.cursor/agents/` 子代理，隔离上下文、专做某类任务 |
| **statusline** | CLI 状态栏 | 配置 `~/.cursor/cli-config.json` 的 statusLine |
| **update-cli-config** | CLI 配置管理 | 查看/修改 Cursor CLI 配置（权限、vim、显示、沙箱等） |
| **update-cursor-settings** | 编辑器设置 | 修改 Cursor/VSCode 的 settings.json（主题、字体、format on save 等） |
| **env-setup** | 环境诊断 | 解释/排查/改进 Cloud Agent 开发环境（`.cursor/environment.json` 等） |

### 迁移与上手

| 命令 | 功能 | 说明 |
|------|------|------|
| **migrate-to-skills** | 规则迁移 | 把「智能应用」规则（.mdc）和 slash commands 迁成 Skills |
| **onboard** | 入门引导 | `/onboard` 轻量引导：问偏好、定目标、产出交接；不做实际安装配置 |

### 代码审查与 PR 维护

| 命令 | 功能 | 说明 |
|------|------|------|
| **review** | 审查入口 | 让你选 Bugbot 或 Security Review，再转对应流程 |
| **review-bugbot** | Bugbot 审查 | 用 Bugbot subagent 审查本地 diff（分支改动/未提交改动） |
| **review-security** | 安全审查 | 用 Security Review subagent 做安全向审查 |
| **babysit** | PR 守护 | 盯 PR 直到可合并：处理冲突、消化评论、修 CI，循环到绿灯 |
| **split-to-prs** | 拆分 PR | 把一大坨改动拆成多个小 PR；先出方案，你批准后再动手 |

### 运行与集成

| 命令 | 功能 | 说明 |
|------|------|------|
| **loop** | 循环执行 | `/loop` 按间隔反复跑某 prompt/技能（如每 5 分钟检查一次） |
| **shell** | 原样执行 | `/shell` 后的文字原样当命令执行，不改写、不「优化」 |
| **sdk** | SDK 集成 | Cursor SDK（TS `@cursor/sdk` / Python `cursor-sdk`）集成指南：脚本、CI、自动化里跑 Agent |
| **canvas** | 可视化画布 | 产出可旁开的可视化 Canvas（`.canvas.tsx`），适合分析报告、图表、MCP 数据结果等 |

### 一句话记忆

- **教 Agent 怎么做事**：rule / skill / hook / subagent
- **改 Cursor 本身**：settings、CLI config、statusline、env-setup、automation
- **看代码质量**：review / bugbot / security / babysit / split-to-prs
- **特殊交互**：onboard、loop、shell、canvas、sdk
