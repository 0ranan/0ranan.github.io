## 附录（关于 sandbox 演讲总结）

### 1. 中移软件虚拟化 agentic infra 高密度弹性沙箱

**总结**

他们提供的方案是一个综合性的 agent 隔离方案，展示出来的方案又多又杂，且项目并不开源。看着热闹，实际上价值不大——拿不到源码分析，就不具备参考价值。

**个人理解**

现在 sandbox 领域存在一个不可能三角：

1. 安全：内核安全且不易存在内核攻击面的隔离沙箱。
2. 高效：能够快速拉起释放的隔离机制。
3. 高功能：快捷的高度适配的快照、会话共享机制。

现在的 sandbox 方案有下面几种：

- 基于 Docker、K8s 的轻沙箱方案。
- 基于 QEMU 等内核独立的重型隔离方案。
- 基于前两者的各种定制沙箱方案。

### 2. 英特尔 IAA 加速

**总结**

英特尔相关的演讲主旋律在于如何使用 zswap 硬编解码相关的方案，通过增加 CPU 占用降低内存占用。（当然，他可能也讲了其他，但已我的水平只能理解那么多了）

**个人理解**

这个方案可以一定程度上缓解 QEMU 等重型隔离方案带来的开销，在 agent 普遍跑在 Node 运行时、高内存占用低 CPU 负载的背景下也适用。这个技术如果拓展，也可以用在办公等其他场景。英特尔在借 agent 的背景推广自己在沙箱领域的硬件技术产品，这是有效的。
