## strstr(字符查找)

```c
char *strstr(const char *str1, const char *str2);
功能：返回str2第一次在str1中的位置，如果没有找到，返回NULL
```


## sscanf正则

```
% 代表选择，后跟相应条件
%* 代表过滤（即连续匹配满足条件的字符，并丢弃）
%及%* 后面紧跟的数字代表匹配的字符个数
%5[^)]代表匹配5个非)的字符，[]内是筛选的条件，^表示否定，如%[a-z]表示接收小写字母，%[A-Z0-9] 表示接收大写字母及数字
要匹配中间的字符时，应先将前面的字符用%*过滤掉
```
