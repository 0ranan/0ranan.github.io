## 0. 指令指南

```bash
[root@localhost dev]# fdisk -h

用法：
 fdisk [options] <disk>         change partition table
 fdisk [options] -l [<disk>...] list partition table(s)

显示或操作磁盘分区表。

选项：
 -b, --sectors-size <大小>     显示扇区计数和大小
 -B, --protect-boot            创建新标签时不要擦除 bootbits 
 -c, --compatibility[=<模式>]  模式，为“dos”或“nondos”(默认)
 -L, --color[=<时机>]          彩色输出（auto, always 或 never）
                                 默认启用颜色
 -l, --list                    显示分区并退出
 -x, --list-details            like --list but with more details
 -n, --noauto-pt               don't create default partition table on empty devices
 -o, --output <列表>           输出列
 -t, --type <类型>             只识别指定的分区表类型
 -u, --units[=<单位>]          显示单位，“cylinders”柱面或“sectors”扇区(默认)
 -s, --getsz                   以 512-字节扇区显示设备大小[已废弃]
     -b, --bytes                   以字节为单位而非易读的格式来打印 SIZE
     --lock[=<模式>]           使用独占设备锁（yes、no 或 nonblock）
 -w, --wipe <模式>             擦除签名（auto, always 或 never）
 -W, --wipe-partitions <模式>  擦除新分区的签名(auto, always 或 never)

 -C, --cylinders <数字>        指定柱面数
 -H, --heads <数字>            指定磁头数
 -S, --sectors <数字>          指定每条磁道的扇区数

 -h, --help                    显示此帮助
 -V, --version                 显示版本

可用的输出列：
 gpt: Device Start End Sectors Size Type Type-UUID Attrs Name UUID
 dos: Device Start End Sectors Cylinders Size Type Id Attrs Boot End-C/H/S
      Start-C/H/S
 bsd: Slice Start End Sectors Cylinders Size Type Bsize Cpg Fsize
 sgi: Device Start End Sectors Cylinders Size Type Id Attrs
 sun: Device Start End Sectors Cylinders Size Type Id Flags

更多信息请参阅 fdisk(8)。
```

  GPT

   n   添加新分区

   t   更改分区类型
   v   检查分区表
   i   打印某个分区的相关信息

   m   打印此菜单
   x   更多功能(仅限专业人员)

## 1. 观察


| 视图|	  命令|	回答什么问题|
|-|-|-|
| 设备视图 | lsblk / lsblk -f	|有哪些盘、怎么分层（disk→part→lvm）、多大、什么文件系统、挂没挂 |
| 挂载视图	| df -hT / findmnt | 内核当前真正挂上了什么、各挂载点容量与余量 |
| 分区表视图 | parted /dev/vda print free / sgdisk -p / sfdisk -d	| 分区起止扇区、空闲区间在哪、GPT 表本身是否健康|
| 卷管理视图 | pvs / vgs / lvs	| LVM 里 PV/VG/LV 各多大、有没有剩余空间 |
| 身份视图 | blkid / lsblk -f | 每个文件系统的 UUID/LABEL（fstab 要用）|

## 挂载

```bash
[root@localhost ~]# mount /dev/vda4 /app
mount: /app: 挂载点不存在.
[root@localhost ~]#  mkdir /app
[root@localhost ~]# mount /dev/vda4 /app
mount: /app: 文件系统类型错误、选项错误、/dev/vda4 上有坏超级块、缺少代码页或帮助程序或其他错误.

```


```bash
# 格式化新分区
[root@localhost app]# mkfs.xfs /dev/vda4 
# 挂载新分区
[root@localhost app]# mount /dev/vda4 /app
# 
```

## 配置自动挂载

```bash
[root@localhost ~]# blkid /dev/vda4
/dev/vda4: UUID="0ea92605-1d34-4855-80c1-51cae3e21f44" BLOCK_SIZE="512" TYPE="xfs" PARTUUID="d0ac5a5b-8029-134b-97b6-e2d0706b1974"
[root@localhost ~]# cp /etc/fstab /etc/fstab.bak
[root@localhost ~]# vim /etc/fstab
```

把下面这行指令加入fstab 的最后一行，其中 uuid为vda4的uuid

```bash
UUID=0ea92605-1d34-4855-80c1-51cae3e21f44 /app xfs defaults 0 0
```

验证配置文件是否正确

```bash
sudo mount -a
```
