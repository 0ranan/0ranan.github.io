# Liunx大杂烩

## Ubuntu换源

•https://mirrors.ustc.edu.cn/repogen/

下载对应版本最新的源

备份原始文件

```shell
sudo cp /etc/apt/sources.list /etc/apt/source.list.bak
```

替换源

```shell
mv -f sources.list /etc/apt/
```

更新软件包索引

```shell
sudo apt update
```

#### 手动安装vbox工具（virtualbox-guest-x11）

```shell
sudo apt-get update
sudo apt-get dist-upgrade
sudo apt-get install virtualbox-guest-x11
```

## linux目录改为英文

```
终端先输入：export LANG=en_US

再输入：xdg-user-dirs-gtk-update
```

跳出选择，点击确定

目录变为英文

转中文用：export LANG=zh_CN.UTF-8

 

再输入：xdg-user-dirs-gtk-update
