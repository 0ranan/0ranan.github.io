# ubuntu26.04手动创建自启动配置文件

## 手动创建自启动配置文件（最可靠）

如果上述设置中找不到 Fcitx5，你可以手动创建一个自启动文件，这是最底层的生效方式：

### 1. 确保自启动目录存在

打开终端，创建自启动目录：

```bash
mkdir -p ~/.config/autostart
```

### 2. 创建 .desktop 文件

使用文本编辑器（如 nano）创建一个 `fcitx5.desktop` 文件：

```bash
nano ~/.config/autostart/fcitx5.desktop
```

### 3. 写入配置内容

将以下内容复制并粘贴到文件中：

```text
[Desktop Entry]
Type=Application
Name=Fcitx5
Exec=/usr/bin/fcitx5
Hidden=false
NoDisplay=false
Comment=Start Fcitx5 Input Method
```

按 `Ctrl + O` 保存，按 `Enter` 确认，然后按 `Ctrl + X` 退出编辑器。
