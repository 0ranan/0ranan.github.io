# swap 空间管理

## swap空间删除

### 第一步：关闭交换空间

在终端中执行以下命令，这会将交换空间中的数据回写到物理内存中（可用内存有 14G，足够容纳这部分数据）：

```bash
sudo swapoff /swap.img
```

### 第二步：删除交换文件

关闭交换后，就可以安全地删除这个物理文件了：

```bash
sudo rm /swap.img
```

### 第三步：取消开机自动挂载（非常重要）

如果不做这一步，下次开机时系统会因为找不到 `/swap.img` 而报错或导致开机变慢。

编辑 `/etc/fstab` 文件：

```bash
sudo nano /etc/fstab
```

在打开的编辑器中，找到包含 `/swap.img` 的那一行（通常在文件最后），它看起来类似这样：

```
/swap.img none swap sw 0 0
```

在这一行的最前面加上 `#` 号将其注释掉，或者直接删除整行：

```
# /swap.img none swap sw 0 0
```

保存并退出：按 `Ctrl + O` 保存（按回车确认），然后按 `Ctrl + X` 退出。

### 第四步：验证是否删除成功

运行以下命令检查：

```bash
sudo swapon --show
free -h
```

如果 `swapon --show` 没有任何输出，且 `free -h` 中的交换那一行显示为 `0B`，就说明你已经完美地删除了之前的交换空间。

## swap空间创建

### 第一步：创建交换文件

使用 `fallocate` 命令可以瞬间分配出 64GB 的空间（因为根目录是 ext4 格式，支持此命令）：

```bash
sudo fallocate -l 64G /swapfile
```

### 第二步：设置正确的文件权限

出于安全考虑，交换文件只能被 root 用户读写：

```bash
sudo chmod 600 /swapfile
```

### 第三步：将该文件格式化为交换空间

```bash
sudo mkswap /swapfile
```

### 第四步：启用交换空间

```bash
sudo swapon /swapfile
```

### 第五步：设置开机自动挂载（永久生效）

刚才注释掉了旧的 `/swap.img`，现在把新的 `/swapfile` 写入 `/etc/fstab`。执行下面这条命令即可自动追加写入：

```bash
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

### 第六步：验证是否创建成功

运行以下命令检查：

```bash
sudo swapon --show
free -h
```

如果 `swapon --show` 显示名为 `/swapfile`、大小为 64G 的记录，且 `free -h` 中交换空间总量变成了 64G，就说明大功告成了！
